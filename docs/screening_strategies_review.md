# 상승 후보 스크리닝 방법 검토 (구현 전 검토 문서)

> 이 문서는 **검토만** 한 내용입니다. 현재 GUI 에는 "거래량 급증 + 가격 횡보" 조건만 구현되어 있습니다.
> 아래 방법들은 투자 권유가 아니며, 실제 매매 전에 반드시 백테스트와 모의투자로 검증하세요.

## 0. 현재 조건(거래량 급증 + 가격 횡보)에 대한 검토

**근거**
- 학계에서는 "평소보다 거래량이 비정상적으로 많았던 종목이 이후 1개월 정도 초과수익을 내는 경향"이
  보고되어 있습니다 (Gervais·Kaniel·Mingelgrin, *The High-Volume Return Premium*, Journal of Finance, 2001).
  관심·가시성이 높아져 매수자가 늘어난다는 해석입니다.
- 가격이 움직이지 않았다는 것은 **누군가 나온 물량을 받아냈다(흡수)** 는 뜻일 수 있어, 매집 신호로 해석하는 실무 관행이 있습니다.

**주의 — 같은 모양이 '나쁜' 이유로도 생긴다**

| 거래량은 터졌는데 가격이 그대로인 원인 | 의미 | 걸러내는 방법 |
|---|---|---|
| 블록딜 · 시간외 대량매매 | 대주주/기관 물량 넘기기 → 이후 약세가 흔함 | DART '최대주주등소유주식변동', '임원ㆍ주요주주 특정증권등 소유상황' 공시 확인 |
| 지수 정기변경(KOSPI200·MSCI 등), 선물·옵션 만기일 | 기계적 거래, 정보 없음 | 해당 날짜 제외(3·6·9·12월 둘째 목요일 전후, 지수 변경일) |
| 유상증자 신주 · CB/BW 전환물량 상장, 보호예수 해제 | 매도 물량 출회(분배) | DART 위험 공시 키워드 — GUI 공시 패널에서 빨간색으로 표시 |
| 관리종목 지정/해제, 거래정지 후 재개 | 이상 거래 | 거래량 배수 상한, 재개 직후 종목 제외 |
| 세력의 '물량 떠넘기기'(분배) | 고점에서 횡보하며 거래량 증가 | 직전 20~60일 상승률이 큰 종목은 감점(위치 조건) |

**개선 제안 (우선순위 순)**
1. **수급 오버레이**: 거래량이 터진 날 외국인·기관이 순매수였는지 확인. 같은 KRX 계정으로
   pykrx `get_market_net_purchases_of_equities_by_ticker` 를 쓰면 추가 비용 없이 가능. "급증 + 보합 + 기관/외국인 순매수"는 흡수(매집) 해석에 훨씬 가깝습니다.
2. **위치 조건**: 최근 60일 저점 대비 상승률이 낮을 때(바닥권·박스권 하단)만 채택 — 고점권 분배를 배제.
3. **이벤트일 제외**: 만기일/지수 변경일 캘린더 필터.
4. **사후 성과 추적**: 신호 발생 후 5·10·20일 수익률을 자동 기록해 파라미터(배수·허용 등락률)를 데이터로 튜닝.

## 1. 수급 기반

| 방법 | 조건 예시 | 데이터 | 비고 |
|---|---|---|---|
| 외국인·기관 동반 연속 순매수 | 최근 5일 중 4일 이상 순매수, 순매수 금액/시총 상위 | KRX(pykrx) | 국내 시장에서 실무적으로 가장 많이 쓰는 필터 |
| 연기금 순매수 | 연기금 N일 누적 순매수 상위 | KRX 투자자별 | 중장기 자금, 대형주에 유효 |
| 공매도·대차잔고 감소 | 대차잔고 20일 감소율 상위 + 주가 횡보 | KRX 공매도 통계 | 숏커버 수요 기대. 공매도 제도 변경에 따라 데이터 연속성 확인 필요 |
| 내부자(임원·최대주주) 장내 매수 | 최근 30일 내 장내매수 보고 | DART 지분공시 | 내부자 매수는 매도보다 정보력이 높다는 연구가 많음 |

## 2. 가격·거래량 패턴(기술적)

| 방법 | 조건 예시 | 현재 조건과의 관계 |
|---|---|---|
| **OBV/누적분산(A/D) 상승 다이버전스** | 가격은 20일 횡보, OBV 는 20일 신고가 | 현재 조건의 '여러 날 버전'. 하루짜리 급증보다 노이즈가 적음 |
| **변동성 수축(VCP)·볼린저 밴드 스퀴즈** | 밴드폭이 120일 최저, 거래량 감소 → 돌파일 거래량 증가 | 급증 이전 단계를 미리 포착 |
| **52주 신고가 근접/돌파** | 종가 ≥ 52주 고가 × 0.95, 돌파일 거래량 2배+ | George & Hwang(2004) 52주 고가 효과. 매물대 없음 |
| **상대강도(RS)** | 지수 대비 3·6개월 수익률 상위 20%, 지수 하락일에 버틴 종목 | 모멘텀. 국내는 단기(1개월) 반전 효과가 강해 직전 1개월은 제외하는 게 일반적 |
| **이평 정배열 + 눌림목** | 5>20>60>120일선, 20일선 근처까지 조정 + 조정 중 거래량 감소 | 추세 추종 진입 타이밍 |
| **갭상승 유지** | 3%+ 갭상승 후 갭을 메우지 않고 마감 | 강한 수요 확인 |

## 3. 실적·공시 기반 (DART 활용)

| 방법 | 조건 예시 | DART API |
|---|---|---|
| **실적 서프라이즈 / 흑자전환** | 분기 영업이익 YoY +50% 이상, 또는 적자→흑자 | `fnlttSinglAcnt` (단일회사 주요계정) | 
| 잠정실적 공시 직후 드리프트(PEAD) | 잠정실적 공시 다음날 갭상승 + 거래량 | `list.json` (공시유형 I: 거래소공시) |
| 대규모 공급계약 | 계약금액 / 최근 매출 ≥ 10% | '단일판매ㆍ공급계약체결' 공시 |
| 주주환원 | 자사주 취득·**소각** 결정, 배당 확대 | 자기주식 관련 공시 |
| 무상증자 | 권리락 전후 | 단기 이벤트성, 변동성 큼 |

실적 기반은 가격 패턴보다 신호가 드물지만 근거가 상대적으로 탄탄합니다 (Bernard & Thomas, 1989 등 PEAD 연구).

## 4. 밸류에이션·퀄리티(중장기)

- **저PBR + 고ROE**: PBR 하위 30% 중 ROE 상위 (기업 밸류업 프로그램 이후 주주환원 공시와 결합 시 유효성이 높아짐).
- **마법공식(Greenblatt)**: 이익수익률(EBIT/EV) + 자본수익률 합산 순위.
- **배당 성장**: 3년 연속 DPS 증가.
- 데이터: pykrx `get_market_fundamental_by_ticker`(PER/PBR/DIV) + DART 재무제표.
- 단기 매매보다는 후보군(유니버스) 압축용으로 쓰고, 위의 수급·패턴 조건을 진입 타이밍으로 결합하는 방식을 권장.

## 5. 조합 추천

1. **매집 포착형** (현재 조건 확장): 거래량 3배+ & 보합 & 외국인/기관 순매수 & 60일 저점 대비 +20% 이내 & 위험 공시 없음
2. **돌파 대기형**: 볼린저 스퀴즈 & OBV 상승 & 52주 고가 대비 -10% 이내
3. **실적 모멘텀형**: 분기 영업이익 흑자전환/급증 & 공시 후 거래량 급증 & RS 상위

## 6. 매매로 연결하기 전 체크리스트

- **백테스트 편향**: 상장폐지 종목 포함(생존편향), 당일 종가로 신호 → 익일 시가 진입(미래참조 금지).
- **비용**: 매도 시 증권거래세 + 수수료 + 슬리피지. 소형주는 호가 공백으로 체결 비용이 큼.
- **손절/익절 규칙**을 사전에 정하고 신호별 성과(승률, 평균 손익비)를 기록.
- 자동매매를 붙인다면 증권사 Open API(예: 한국투자증권 KIS Developers 등)를 사용하고, 반드시 모의투자 계좌에서 먼저 검증.
- KRX·DART 데이터 이용약관(재배포 금지, 호출 빈도)을 준수.
